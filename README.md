# 🧠 GPT-Neo Text Generator (Free & Open Source)

This is a fully local, free, and open-source text generation web app built with **Streamlit** and powered by **EleutherAI's GPT-Neo 1.3B** model.

## 🚀 Features
- GPT-Neo text generation (no OpenAI API)
- Short or detailed responses
- Translation into 10+ languages (via Deep Translator)
- Copy to clipboard
- Download as `.txt` (coming soon)
- Fully Streamlit-powered

## 📦 Installation

```bash
pip install -r requirements.txt
```

Then run:

```bash
streamlit run gpt_text_generator_app.py
```
